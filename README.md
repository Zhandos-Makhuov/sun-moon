# Солнце и Луна

Кооперативный платформер для двоих в одном файле `index.html` — просто откройте его в браузере.

- **Компьютер:** Солнце — `A` `D` ходьба, `W` прыжок, `S` свой свет; Луна — `←` `→`, `↑` прыжок, `↓` своя тьма. `R` — заново, `Esc` — меню.
- **Телефон:** горизонтальный экран, слева кнопки Солнца, справа — Луны.

Солнце безопасно на свету, Луна — во тьме. Золотые платформы держат только Солнце, сиреневые — только Луну.
10 уровней, механики появляются по одной: цветные платформы, лучи и звёзды, кнопки, затмение, фонари и тучи, свой свет, смена дня и ночи.

Параметр `?all` открывает все уровни, `?level=N` сразу запускает уровень N.
